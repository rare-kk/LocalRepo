# Kumkum | Devi Banaras Photography

A personal photography portfolio website for Kumkum, based in Delhi, India. The site presents a refined, cinematic aesthetic and highlights her work as a researcher, traveller, and photographer.

## About
Kumkum, also known as Devi Banaras, creates visual stories that blend travel, research, portraiture, and emotional storytelling. This portfolio website reflects her identity through curated imagery, thoughtful typography, and a clean premium layout.

## Features
- Elegant luxury-style photography landing page
- Responsive layout for desktop and mobile
- Portfolio gallery section
- About / story section
- Process or approach section
- Client testimonials
- Contact form that opens the user’s default email client with inquiry details
- Personal branding with Delhi-based identity

## Tech Stack
- HTML
- CSS
- JavaScript
