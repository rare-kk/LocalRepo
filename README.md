# Luma Frame Photography

A stylish photography landing page built with HTML and CSS. This project showcases a modern portfolio layout for weddings, portraits, travel, and editorial photography.

## Features
- Elegant dark luxury aesthetic
- Responsive layout for desktop and mobile
- Portfolio gallery with image cards
- About section and service highlights
- Testimonials and contact call-to-action
- Sticky navigation and CTA buttons
